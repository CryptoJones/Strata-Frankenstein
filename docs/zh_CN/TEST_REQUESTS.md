# 请求的测试与想要的硬件
<a id="test-requests-and-hardware-wanted"></a>

Strata 只在少数几台机器上构建和测量。来自其他硬件的结果很受欢迎，而且会被采用：它们能告诉我们某个 setup 真实的表现，也能指出引擎在哪里选错了。请按 [COMMUNITY_BENCHMARKS.md](COMMUNITY_BENCHMARKS.md) 里描述的方式写报告：构建方式、显卡与 PCIe 宽度、CPU 与内存速度、模型文件、完整命令、每个规模三次运行，以及你没有测到的部分。把它发在 issue 里，或者发在相关的 pull request 上。

这份清单由维护者编辑。只要还没有报告回答它，条目就会一直保留。

| 想要的 | 原因 | 早先回答的示例 |
|---|---|---|
| 两块不同大小的 NVIDIA 显卡（一大一小），两种卡序都测，使用 `--layer-split auto` | 这里没有不等大的显卡对来检验切分规划器；卡序和小卡的空闲显存都改变过切分结果 | #880, #1238 |
| 三块或四块 NVIDIA GPU | 这里没有那种规模的多 GPU NVIDIA 机器 | #880 |
| Pascal（sm_61：Tesla P40、P100、GTX 10 系列） | 较老的卡走 fp32 路径，行为可能和新卡不同 | #875, #876 |
| 内存 32 GB 或更少的 Linux 主机 | 专家层文件分层和常驻模式取决于模型有多大一部分能装进内存 | #1194 |
| 在切分或常驻 setup 上做长时间压测（连续请求一小时以上） | 能暴露短跑看不到的崩溃、漂移和过热 | #848 |
| AMD RX 7000 系列（RX 7900 XTX、7900 XT、7800 XT 及类似型号，RDNA 3），Linux 或 Windows | 我们的 RX 7000 构建还没有在真实的 RX 7000 卡上跑过；给它们的 Docker 镜像也没有在卡上测过 | 暂无 |
| Windows + AMD 显卡：应用或终端版，一个模型，发一张图 | Windows 的 AMD 构建还没有在真实卡上跑过，它的图片读取器也没有（显存 24 GB 以下用 CPU，24 GB 起用 GPU） | 暂无 |
| Apple silicon 的 Mac（macOS 15 或更新）：应用或终端版加载真实模型 | Mac 构建只在极少数 Mac 上跑过。请告诉我们 Mac 的内存、模型、速度，以及任何出错的地方。Mac 应用还没有图片读取器。签名脚本还没有针对 Apple 真实的公证服务跑过，所以首次启动出现警告是预期内的，也值得反馈 | 暂无 |

要新增一条请求，请开一个 pull request 加一行，或者在 issue 里告诉维护者。
